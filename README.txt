WBL Lerntrainer fuer Android (PWA) - 404 Fragen

DIESE FUENF DATEIEN ins Hauptverzeichnis deines GitHub-Repositories hochladen:
1. index.html
2. manifest.webmanifest
3. service-worker.js
4. icon.png
5. README.txt

GitHub: Repository > Add file > Upload files > Commit changes.
Settings > Pages > Deploy from a branch > main > /(root) > Save.
Warten, bis GitHub Pages veroeffentlicht ist.
Auf dem Android-Handy die GitHub-Pages-Adresse in Chrome oeffnen.
Chrome-Menue (drei Punkte) > App installieren / Zum Startbildschirm hinzufuegen.

Die App ist eine Progressive Web App (PWA), KEINE APK.
Zum Offline-Lernen die Seite einmal vollstaendig mit Internetverbindung laden.
Bei Aktualisierungen ggf. die Seite neu laden.

Funktionen: 404 Fragen, Referenzen auf Klick, Antwortmischung, Teilauswertung, Fehlertraining.
